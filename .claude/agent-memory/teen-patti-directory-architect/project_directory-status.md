- **Two real bugs found and fixed in the countdown feature**: (1) `UpcomingGameCard`'s clock hook originally passed a new inline `subscribe` function to `useSyncExternalStore` every render, causing React to re-subscribe → fire an update → re-render → re-subscribe forever ("Maximum update depth exceeded") — fixed with a module-level singleton clock (stable function references). (2) Unrelated dev-mode-only issues also fixed: CSP blocking `eval()` broke React Fast Refresh in dev (now `unsafe-eval` is allowed only when `NODE_ENV === "development"`, production CSP unchanged/strict), and `suppressHydrationWarning` added to `<html>`/`<body>` for browser-extension DOM pollution (e.g. Bitdefender's `bis_skin_checked` attribute) — genuinely not a code bug, just noisy in dev tools.
- **Dev-environment flakiness, not code bugs**: this machine intermittently throws transient errors unrelated to any actual change — `npm` spawn errors ("Could not determine Node.js install directory", `EUNKNOWN: unknown error, uv_spawn`), and Turbopack dev-server IPC panics ("connection forcibly closed by the remote host", os error 10054) that 500 every page until restarted. Retry once before assuming a real bug; the fix is always the same: kill the dev-server PID, `rm -rf .next`, `npm run build` to confirm clean, then restart dev.
